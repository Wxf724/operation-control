# 首页与作业管理自动巡览

- 打开或刷新任意页面时自动从首页地图开始巡览，无需地址参数；开发版与离线包一致。
- 外部控制：同源页面调用 `window.cockpitTour.start()`、`window.cockpitTour.stop()`。重复开始会取消上一轮；停止立即取消等待，不再跳转，停留当前页面。
- 用户在页面任意位置真实点击或触屏按下，立即中断并保留点击本身的操作；键盘触发按钮点击也会中断。程序巡览点击不触发中断。中断后保持手动操作，刷新或重新打开才自动重启。
- 固定 25 步，每步动作后停留 10 秒，约 4 分 10 秒一轮，额外计入入口等待时间。结束返回地图并无限循环。
- `steps.ts` 是路线白名单；只点击现有模块入口、标题、页签和返回按钮。钻取返回使用 history 后退，不改日期、组织、口径筛选，不发送问答或提交表单。
- 页面不增加控制器、状态条或进度提示。入口 6 秒未就绪时停止并记录控制台错误，避免误点其他控件。
- `GuidedTour.tsx` 负责计时、取消和入口就绪等待；无需引入额外依赖。
