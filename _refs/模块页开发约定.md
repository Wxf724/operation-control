# 模块平台页开发约定

给并行开发各模块平台页的 agent 看。**先完整读完再动手。**

## 你要产出什么

针对指定的一个模块，产出两个文件（不要改其它任何文件）：

1. `src/pages/platform/modules/<Name>PlatformContent.tsx` —— 中间业务区组件
2. `src/pages/platform/modules/<name>Data.ts` —— 该页的模拟数据

导出一个具名函数组件：

```tsx
export function XxxPlatformContent() {
  return <div className="flex min-h-0 flex-1 gap-2.5">{/* 你的分栏 */}</div>
}
```

**根元素必须是 `<div className="flex min-h-0 flex-1 gap-2.5">`**，它会被直接放进平台页的内容行里，右边紧挨着固定 780px 宽的右栏。不要自己再画顶栏、KPI 卡条、AI 调控策略、调控执行反馈——那四块是公共的，已经做好了。

不要注册路由，不要改 `registry.ts`，我会统一接。

## 参考截图

在 `_refs/live/` 目录下，用 Read 工具直接读 png（Read 支持图片）。**按截图 1:1 还原版面：分几栏、每栏哪些面板、每个面板里有哪些图表和数字。** 数值照抄截图，看不清就填一个合理的近似值，但不要臆造截图里根本没有的面板。

## 可用的公共组件

从 `@/components/cockpit-ui` 导入：

- `PanelBox` —— 带四角装饰和标题栏的面板外壳。`<PanelBox title="标题" extra={右上角内容} className="flex flex-col ...">`
- `SectionTitle` —— 面板内的二级小标题（带菱形标记），对应截图里「◆ 某某情况」那种
- `StatusTag` —— 状态标签，`tone` 取 `cyan|blue|green|orange|red|purple|muted`，`variant` 取 `solid|soft|plain`
- `ProgressBar` —— 细条进度，`value` 0–100
- `useChartColors()` —— 返回主题色值对象，**ECharts 必须用它取色**，见下

## 硬性规范

1. **禁止硬编码颜色**。一律用 CSS 变量：`text-(--ck-cyan)`、`bg-(--ck-panel-inner)`、
   `border-(--border)`，或行内 `style={{ color: 'var(--ck-red)' }}`。
   可用变量：`--ck-cyan --ck-blue --ck-green --ck-orange --ck-red --ck-purple --ck-yellow --ck-pink`、
   `--ck-title --ck-title-sub --foreground --text-secondary --text-tertiary`、
   `--ck-panel-inner --ck-panel-inner-border --ck-table-head --ck-table-row --ck-table-row-alt`、
   `--ck-grid --ck-axis`。
   半透明用 `color-mix(in srgb, var(--ck-red) 18%, transparent)`。
   渐变、阴影这类装饰性的 rgba 可以写字面值。

2. **ECharts 取色必须走 `useChartColors()`**，canvas 渲染解析不了 `var()`：

   ```tsx
   const c = useChartColors()
   const option = useMemo(() => buildOption(c), [c])
   // buildOption 里用 c['--ck-cyan'] 这种方式取色
   ```

   图表用 `import ReactECharts from 'echarts-for-react'`，容器给 `style={{ height: '100%', width: '100%' }}`，
   并加 `opts={{ renderer: 'canvas' }}` 和 `notMerge`。
   `backgroundColor: 'transparent'`，`textStyle.fontFamily: 'Noto Sans SC, sans-serif'`。

3. **环形图/仪表盘/进度环优先用内联 SVG 手写**，不要为每个小圆环都起一个 ECharts 实例。
   柱状图、折线图用 ECharts。

4. 尺寸用 Tailwind 任意值，如 `h-[216px]`、`w-[640px]`、`text-[13px]`。画布是 2400×1080，
   内容行可用高度约 **900px**，中间业务区可用宽度约 **1580px**。按截图比例分配。

5. 命名：组件 PascalCase，数据常量 UPPER_SNAKE_CASE，类型用 `interface`，
   **用具名导出，不要 `export default`**。接口和导出函数加 `/** */` 注释。

6. Import 顺序：第三方 → `@/` 别名 → 类型 → 相对路径，组间空行。

7. 文件别超 500 行；超了就把面板拆成同目录下的多个文件。

## 自检

写完后在项目根目录跑：

```
npx tsc --noEmit --project tsconfig.app.json
npx eslint src/pages/platform
```

tsc 的输出里会有两个**模板自带的历史报错**（`src/components/tree/Tree.tsx` 和
`src/components/tree-select/demo.tsx`），不是你引入的，忽略即可；除此之外必须零错误。
eslint 必须零告警。

## 回报

只说三件事：产出的文件路径、页面分了几栏各是什么面板、tsc/eslint 是否干净。
不要贴代码。
